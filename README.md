## About Me

I'm a Houston-based developer with an M.S. in Computer Science. I like working on both the technical and visual sides of a project, whether that's building an API, making sense of a messy dataset, or designing an interface that feels good to use.

My projects range from full-stack applications and data systems to websites, dashboards, and animation. I'm especially interested in software development, data engineering, and projects where problem-solving and creativity overlap.

## What I'm Building

### 🏥 [Healthcare Provider Master Data System](https://github.com/monkikat/provider-mdm-pimcore)

Building a system that brings together simulated EHR, HR, and credentialing records using CMS NPPES data. I'm focusing on cleaning and matching records across sources to create reliable provider profiles.

`Python` `SQL` `Pimcore` `Docker` `ETL` `Master Data Management`

---

### 🌐 [Chosen Prospects — Training Website](https://chosenprospects.org/home)

Designed and developed a website for a baseball and softball training business. The project brought together responsive layouts, clear program information, and a straightforward path to booking and registration.

`Next.js` `Web Design` `Responsive UI` `User Experience`

---

### 🚀 [SpaceMonki](https://github.com/monkikat/SpaceMonki)

Built a full-stack TypeScript app that brings in astronomy content through NASA's APOD API. I worked on the frontend, backend integration, API requests, and deployment.

`TypeScript` `React` `Node.js` `REST APIs`

---

### 🤖 [OCR Language Tutor](https://github.com/monkikat/gcw-mathpix-ocr-language-chat)

Built an accessibility-focused language-learning tool that uses OCR and AI to turn images of conversations into learning material, with a web interface for interacting with the results.

`TypeScript` `React` `OCR` `AI` `APIs`

---

### 🩺 [Type 2 Diabetes Risk Analysis](https://github.com/monkikat/nhanes-diabetes-risk-analysis)

Working on a machine learning workflow using NHANES healthcare data, from dataset preparation and feature engineering to predictive models and evaluation.

`Python` `pandas` `Machine Learning` `Healthcare Data`

---

### 📊 [Title I School Data Analysis](https://github.com/monkikat/Title-1-Schools-New-Jersey-Data-Analysis)

Combined New Jersey education datasets to explore Title I schools, enrollment, and geographic patterns. The project includes data preparation, analysis, and a dashboard for exploring the results.

`Python` `pandas` `Data Analysis` `Looker Studio`
